# Sample lender: loan decisions

A made-up sample codebase for Pulse Risk Monitor's worked example. It is not a real firm's code, is not run anywhere,
and holds no real data.

The sample firm is a consumer lender selling online personal loans in Ireland and the United Kingdom. A machine-learning
model scores each application: below the cut-off it is declined with reason codes, above it an underwriter decides. An
AI model drafts the decline letters. The model is retrained each month; decision logs are kept for 400 days in Ireland
and the United Kingdom.

Point Pulse Risk Monitor's "Start from your code" at this repository to see how it reads a codebase.
